### Inclusion Criteria
- Peer-reviewed papers or preprints (2022–2025)
- Topic: finger vein recognition, segmentation, or related cross-domain transfer
- Reports quantitative results on standard benchmarks (FV-USM, SDUMLA-HMT, HKPU, THU-FVFDT2)

### Exclusion Criteria
- Pure preprocessing pipelines without end-to-end learning
- Handcrafted feature methods (pre-deep-learning era)
- Tangential work (face/iris recognition only)

## 3. Thematic Synthesis

Recent finger vein recognition (FVR) methods cluster into **four architectural paradigms**:

### Theme A: Attention-augmented CNNs
**Representative:** AttenD3 Net, DenseNet with Channel Attention (Devkota & Kim, 2024)

| Aspect | Detail |
|--------|--------|
| **Claim** | Channel + spatial attention filters background noise and directs focus on vein patterns |
| **Advantage** | Lightweight, low inference cost, easy to deploy |
| **Limitation** | Limited receptive field; weak on global context |
| **Performance** | 97.5% accuracy on FV-USM (Densenet121 + CA) |

### Theme B: Hybrid CNN–Transformer Architectures
**Representative:** FVTCNet (2024), FVCT (2023), FV-DMHN (2024), VeinCnnformer (2024)

| Model | Datasets | EER / Accuracy |
|-------|----------|----------------|
| **FVTCNet** | FV-USM / SDUMLA-HMT / HKPU | 99.86% / 99.11% / 99.15% |
| **FVCT** | 3 FV datasets | weighted EER = 0.21% |
| **FV-DMHN** | FV-USM / SDUMLA-HMT / THU-FVFDT2 | EER 0.087% / 0.378% / 0.643% |
| **VeinCnnformer** | 3 public vein DBs | State-of-the-art reported |

**Common motivation:** CNN captures local texture (vein cross-sections), Transformer captures global topology (vein tree). Hybrid fusion (feature-level or mixed) consistently outperforms either alone.

### Theme C: Diffusion & Generative Models
**Representative:** DiffVein (Liu et al., TCSVT 2024), FVeinSyn / FingerVeinSyn-5M (Wang et al., ACM MM 2025)

| Method | Use Case | Result |
|--------|----------|--------|
| **DiffVein** | Unified diff network for segmentation + authentication | EER < 1% on 3 datasets |
| **FingerVeinSyn-5M** | Synthetic pretraining (5M images, 50k identities) | +53.91% gain when fine-tuned on real data |

**Key insight:** The data scarcity bottleneck — which limited FVR for years — is now being addressed by **synthetic pretraining**. FingerVeinSyn-5M is the first fully annotated large-scale dataset.

### Theme D: Federated & Privacy-Preserving
**Representative:** PAFedFV (2024), DDP-FedFV (2024)

| Aspect | Detail |
|--------|--------|
| **Goal** | Train on multi-user data without exposing biometric templates |
| **Limitation** | Degraded accuracy vs. centralized training; convergence issues |
| **Trend** | Personalized + asynchronous (PAFedFV) to mitigate client drift |

### Theme E: Multimodal Biometric Fusion
**Representative:** Fingerprint–Vein Fusion (MDPI 2025), CFVNet (cancelable)

| Fusion Strategy | Accuracy (NUPT-FPV) | EER |
|-----------------|---------------------|-----|
| Feature-level | 99.18% | 0.0024 |
| Score-level | 99.35% | 0.0021 |
| **Hybrid (0.7 score + 0.3 feature)** | **99.79%** | **0.0018** |

**Insight:** Hybrid fusion dominates; multimodal robustness persists across environmental degradation.

## 5. Cross-Cutting Trends

| Trend | Evidence |
|-------|----------|
| **Hybrid CNN-Transformer wins** | FVTCNet, FVCT, FV-DMHN, VeinCnnformer all outperform pure CNN/ViT |
| **Attention is the norm** | ≥ 70% of 2024 papers use some form of attention (channel / spatial / self-attention) |
| **Data scarcity solved by synthesis** | FingerVeinSyn-5M closes the gap; pretraining + fine-tune is the new pipeline |
| **Federated learning emerging** | 2024 saw PAFedFV, DDP-FedFV — privacy concerns are now driving FVR |
| **Lightweight backbones** | MobileNet, Mobile-ViT, Lite-HDNet for embedded deployment |

## 6. Gap Analysis (Research Opportunities)

| # | Gap | Opportunity |
|---|-----|------------|
| 1 | **Cross-domain transfer** | Most methods still train + test on same dataset; no unified cross-domain FVR protocol |
| 2 | **Synthetic-to-real gap** | FingerVeinSyn-5M improves +53.91% but the gap to oracle is still unmeasured |
| 3 | **Few-shot benchmarks** | Many papers don't report 1-shot / 5-shot results clearly |
| 4 | **Anti-spoofing** | Finger vein anti-spoofing is largely unstudied (vs palm vein PVASD) |
| 5 | **Standardized metric reporting** | Some papers report EER, others accuracy — needs unified protocol |
| 6 | **Real-world deployment** | Few papers test on mobile/embedded hardware with latency constraints |

## 9. Recommendation for `FingerVeinSyn-5M` Project

Based on this review, the repo's positioning as **a synthetic pretraining foundation** is well-aligned with the current SOTA — which is increasingly hybrid CNN-Transformer fine-tuned from large-scale pretraining. Open opportunities:

1. Benchmark hybrid architectures (FVTCNet, FV-DMHN) on FingerVeinSyn-5M pretrained weights
2. Report cross-domain transfer (e.g., train on synthetic → test on FV-USM, SDUMLA-HMT)
3. Add 1-shot / 5-shot protocol (currently missing in many SOTA papers)
4. Pair with anti-spoofing benchmark (PVASD-style for finger vein)
